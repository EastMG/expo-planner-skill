# 工具与坑

一站放齐：**每类信息用哪个工具** + **每个环节会翻车的地方**。SKILL.md 不再重复这些内容。

---

## 一、工具清单

| 要什么 | 用什么 | 关键点 |
|---|---|---|
| 读官网/票务页正文 | 浏览器打开后取 `innerText` | 页面是前端渲染，直接抓只得到标题壳 |
| 找页面里的情报长图 | 枚举 `img`，按 `naturalWidth > 300` 过滤 | 长图就是整本手册，尺寸常在 1500×7000+ |
| 下载图 | `Invoke-WebRequest` 到工作区 | 别写 `%TEMP%`（见坑 §5） |
| 长图切片 | Pillow，1400px 一条，宽缩到 1500 | 文件名必须 `ocr_*.jpg` |
| 长图转文字 | `ocr_frames.py`（本机 RapidOCR） | 必须关变化检测，参数见下 |
| 摊位号 / 满赠规则 | 搜索 + 摊主自己的微博/小红书/米游社/抖音 | 与官方导览图交叉验证 |
| 嘉宾分日 | 官方公告（通常是 OCR 出来的表） | 一般只到「时段」粒度 |
| 个人行程 | UP 主/coser 主页**签名**、置顶动态、微博行程条 | 最容易过期，标抓取日期 |
| 关注列表 | `bili user following --page N --size 50` | **没有 `--limit`** |
| 视频内容 | `bili video watch <BV>` | 有 AI 摘要+字幕，比逐帧看快 |
| 我的偏好 | 本地 B站 历史库（MCP `bilibili-history` 或只读 SQLite） | 聚合用 SQL，别逐条读接口 |
| 通勤路径 | 地图脚本 `route --mode transit / driving` | 公交/驾车各算一次 |
| 首末班车 | 地铁官网 / 站表 / 本地宝 | **地图服务不返回首末班** |
| 天气 | 气象台页面或地图脚本的 weather | 早晚温差决定要不要提外套 |

OCR 固定参数（关掉变化检测，否则静态长图被判「没变化」漏读大半）：

```text
ocr_frames.py --frames <切片目录> --out-dir <输出目录> \
  --diff-threshold 0 --change-frac 0 --max-gap 1
```

## 二、坑（按环节）

### 1. 页面

- **JS 渲染**：`fetch` 一个官网新闻页，正文经常只剩标题；必须用浏览器取渲染后的文本。
- **正文为空不代表没内容**：详情全在长图里，不 OCR 等于没看。
- **折叠的「全文」**：微博/米游社公告的规则（签赠、满赠）常在折叠段里。

### 2. 图片与 OCR

- 文件名必须 `ocr_*.jpg`，否则直接报 `no frames matching`。
- **必须**带 `--diff-threshold 0 --change-frac 0`：脚本默认做画面变化检测，对静态长图会误判没变化。
- 切片太高（>1600px）会切断表格行，太低会丢上下文；**1400px 左右**最稳。
- 缩放宽度别低于 1500，小字会糊。
- **OCR 会认错相似字符**：`0/O`、`1/I/l`、`D/O`、`4/14`、`6/16`。摊位号、时间、人数这类关键数字，必须拿第二个来源校正（摊主自述、官方文字版公告）。

### 3. 票务

- **快速票与普通票入场常差 1 小时**，直接决定限定款和前排。
- **单日票 1 次入场** + **停止入场时间早于闭馆**（常见 15:00 / 16:30）→ 中午出馆吃饭就回不来。
- 强实名 + 人脸：借证件、转让都无效，方案里不要出现「找人多买一张」。
- 套票与单票的限购额度可能共享，写清楚"我这张是哪种"。

### 4. 行程

- 官方只给「上午/中午/下午」，把估算写成确定时间，现场会被打脸。
- 个人签名的行程**一周就过期**，且可能只写"某天在"、不写展位。
- 昵称匹配要精确到**账号**：同名/近似名很多，模糊匹配会把无关内容算成人气。

### 5. 通勤

- 地图服务只给路径与耗时，**不给首末班**。
- 站间耗时按「站数 × 2 分钟」估，与地图总时长对不上时以地图为准。
- 末班卡点要**逐段减**（出馆步行 → 站厅 → 换乘步行 → 缓冲），不能拿「演出结束 + 10 分钟」估。
- 大型活动散场会限流、地铁排队，缓冲给 10 分钟不够就写"直接打车"。

### 6. 数据

- B站 web 历史接口**只回溯约 3 个月**，且必须 `max` + `view_at` 双游标，少传一个就永远返回第一页。
- 本地历史库的分年表里，较早年份**可能没有时间戳**（只能按标题/UP 搜，不能排时间轴）。
- 关注列表有上限（5000），翻页参数只有 `--page` / `--size`。

### 7. 输出

- 不许编钟点；不确定就写「估算」+ 依据。
- 没抢到的福利直说，不要用排程粉饰。
- 用户说"不排场内行程"，就别写"几点去哪个馆"。

## 三、环境约束

- **沙箱**：Python 进程写 `%TEMP%` 可能被拒，中间产物一律放工作区。
- **长输出**：命令输出超过一屏先落盘再读，不要重复跑。
- **写死路径集中管理**：本机的库路径、脚本路径统一放工作区的 `NOTE.md`，skill 里只写「见 NOTE.md」。
